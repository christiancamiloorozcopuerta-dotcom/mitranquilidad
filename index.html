Auditoría Forense Inmobiliaria

Qué revisan nuestros abogados en su Certificado de Tradición

Un Certificado de Tradición y Libertad puede tener 5 o 40 anotaciones históricas. Nosotros cruzamos cada código registral para proteger su patrimonio en 4 frentes críticos:

1. Falsa Tradición y Sucesiones

Verificamos que quien vende sea dueño del Dominio Pleno (X) y no de simples "derechos y acciones", posesiones sin título o sucesiones ilíquidas que ningún banco financia.

2. Hipotecas Abiertas vs. Canceladas

Cruzamos las hipotecas bancarias antiguas o en mayor extensión del constructor contra las escrituras posteriores de cancelación para confirmar que el inmueble esté libre de deuda.

3. Embargos, Demandas y Valorización

Detectamos medidas cautelares vigentes por cobros ejecutivos, embargos de tránsito o impuestos municipales, demandas civiles inscritas o gravámenes de valorización.

4. Patrimonio de Familia y Afectación

Identificamos limitaciones al dominio como Patrimonio de Familia Inembargable, Afectación a Vivienda Familiar o usufructos que bloquean la venta en Notaría.

Guía Rápida en 4 Pasos para Activar tu Cerebro Oculto en Cloudflare:

  1. En tu cuenta de Cloudflare ve al menú lateral Workers & Pages → haz clic en Create Worker y ponle de nombre motor-mitranquilidad.
  2. Haz clic en Edit Code, borra el código de ejemplo, pega el código de abajo y dale a Deploy.
  3. En ese Worker ve a Settings → Variables and Secrets y agrega dos variables: GEMINI_API_KEY (tu llave gratuita de Google AI Studio) y PARTNER_SECRET (ej. SOCIO-MT-2026).
  4. Pega la URL de tu Worker en la Pestaña 2 de este panel. ¡Listo! Nadie en internet podrá ver jamás que usas IA ni leer tu Prompt Maestro.

export default {
  async fetch(request, env) {
    const corsHeaders = {
      "Access-Control-Allow-Origin": "*",
      "Access-Control-Allow-Methods": "POST, OPTIONS",
      "Access-Control-Allow-Headers": "Content-Type, X-Partner-Secret"
    };

    if (request.method === "OPTIONS") {
      return new Response(null, { headers: corsHeaders });
    }

    // 1. Verificar clave privada del socio
    const secret = request.headers.get("X-Partner-Secret");
    if (env.PARTNER_SECRET && secret !== env.PARTNER_SECRET) {
      return new Response(JSON.stringify({ error: "No autorizado" }), {
        status: 401,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }

    try {
      const body = await request.json();
      const parts = [{ text: body.prompt }];

      if (Array.isArray(body.files)) {
        for (const f of body.files) {
          parts.push({
            inlineData: { mimeType: f.mimeType, data: f.base64 }
          });
        }
      }

      const apiUrl = `https://generativelanguage.googleapis.com/v1beta/models/gemini-3-flash-preview:generateContent?key=${env.GEMINI_API_KEY}`;
      const res = await fetch(apiUrl, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({
          contents: [{ role: "user", parts }],
          systemInstruction: { parts: [{ text: body.systemPrompt }] },
          generationConfig: { responseMimeType: "application/json" }
        })
      });

      const data = await res.json();
      const jsonText = data?.candidates?.[0]?.content?.parts?.[0]?.text || "{}";
      return new Response(jsonText, {
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    } catch (err) {
      return new Response(JSON.stringify({ error: err.message }), {
        status: 500,
        headers: { ...corsHeaders, "Content-Type": "application/json" }
      });
    }
  }
};
